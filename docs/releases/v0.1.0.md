### 先体验，不用交出你的简历。

离线演示无需邮箱授权、真实个人资料或模型账号。macOS / Linux 上，安装好 Python 3.9+ 后运行：

```sh
git clone https://github.com/milkrabbitt/job-search-harness.git
cd job-search-harness
./scripts/doctor.sh
./scripts/bootstrap.sh --demo
./scripts/serve.sh
```

打开 **http://127.0.0.1:8876/**。按 **Ctrl+C** 停止。SQLite 与时区数据要求由诊断脚本检查。

不熟悉命令行？[把安装提示词交给你的编程助手 →](https://github.com/milkrabbitt/job-search-harness#ai-install)

### 把记录留在自己手里，把选择留给自己。

- **本地运行**：Python + SQLite；支持备份与恢复。
- **过程可核验**：查重、过期草稿检查、附件校验、暂停外发；邮件结果不明时先核验。
- **源码可扩展**：MIT 开源，可以按自己的求职习惯修改。

**验证依据：**当前套件 75 项离线测试通过，覆盖上述关键路径。[macOS / Ubuntu CI](https://github.com/milkrabbitt/job-search-harness/actions/runs/42855871677)

<details>
<summary><strong>v0.1.0 的支持范围与接入方式</strong></summary>

这是预览版。基础演示支持 macOS / Linux，原生 Windows 暂不支持；当前界面为中文。网易 126 邮箱与猎聘授权接入依赖 macOS 钥匙串。站内聊天和申请需要操作者在浏览器中完成。可选模型复核通过本机已登录的 Codex CLI 调用，演示不依赖模型。

本地运行不等于永不联网：启用招聘渠道或模型后，相应内容会发送到所配置的服务。所有接入要求见[渠道说明](https://github.com/milkrabbitt/job-search-harness/blob/main/job_harness/CHANNELS.md)。

Companies have recruiting systems. Your job search deserves one too.

Job Search Harness brings listings, match evidence, application materials, recruiter conversations and next decisions into a workspace that runs on your computer. Pick up where you left off.

Try the offline demo with fictional data—no real résumé, email credentials or model account required. macOS / Linux, Python 3.9+. The current UI is in Chinese. Some live integrations require macOS Keychain; platform actions use human browser handoff.
