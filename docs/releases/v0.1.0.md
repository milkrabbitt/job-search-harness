## Job Search Harness v0.1.0 预览版

Job Search Harness 在本机整理岗位、申请和招聘回复。你先设置岗位方向、城市、薪资要求等条件，并登记经历和已批准的简历 PDF。工作台可以检查已配置的招聘来源、根据 JD 列出匹配理由、准备申请草稿，并保留发送凭据。简历不需要传到演示环境。

- **岗位与薪资：** 合并能确认重复的岗位，区分匹配、不符合和未说明的条件。岗位页显示招聘方公开的薪资区间，可按自己设定的底线筛选；投递台账可导出 CSV。
- **招聘消息：** 已同步或登记的消息可按岗位查看。网易 126 接通并授权后，可按规则回复部分明确的材料请求与有依据的简单问题。面试时间、薪资和 Offer 由本人决定。
- **渠道范围：** 官网表单、BOSS 直聘、猎聘和鱼泡的站内提交与聊天仍需浏览器接管。猎聘的候选人授权用于职位搜索；可选的 Codex CLI 用于复核有限的匹配信息。

### 试用离线演示

演示使用虚构岗位、简历和招聘消息，回执来自本机模拟，不会外发。需要 macOS 或 Linux、Python 3.9+；SQLite 和时区数据可用诊断脚本检查。

```sh
git clone https://github.com/milkrabbitt/job-search-harness.git
cd job-search-harness
./scripts/doctor.sh
./scripts/bootstrap.sh --demo
./scripts/serve.sh
```

在浏览器打开终端显示的地址（默认 `http://127.0.0.1:8876/`）。按 **Ctrl+C** 停止。[安装提示词](https://github.com/milkrabbitt/job-search-harness#ai-install) · [渠道说明](https://github.com/milkrabbitt/job-search-harness/blob/main/job_harness/CHANNELS.md) · [macOS / Ubuntu CI](https://github.com/milkrabbitt/job-search-harness/actions/runs/42855871677)

### English

Job Search Harness keeps job listings, applications and recruiter replies on your computer. Set role, location and pay preferences, register a local résumé PDF, and review why roles from your configured sources match. The workspace keeps drafts, delivery evidence and recruiter threads that were synced or recorded. With authorized NetEase 126 mail, it can handle some routine replies; interviews, compensation and offers stay with you. The offline demo uses fictional data and sends nothing. The current interface is in Chinese.
