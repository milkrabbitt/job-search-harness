# Job Search Harness 中文发布文案

## 一句话介绍

Job Search Harness 是一个本地运行的 AI 求职工作台，把岗位整理、申请准备和招聘跟进串成完整流程。

## 社交平台短帖

你的下一份工作，值得一套更好的工具。

收藏的岗位、写到一半的申请、等你确认的面试，终于能放在同一个地方。Job Search Harness 记录为什么值得投、用的是哪版简历、下一步该做什么。

少一点复制粘贴，少一点遗漏，多一点有准备的机会。开源版附带虚构数据和模拟发送，几条命令就能体验。

[GitHub 上体验 Job Search Harness](https://github.com/milkrabbitt/job-search-harness)

## 长帖

求职很容易被琐事切碎。一个岗位留在浏览器收藏夹，一份简历卡在邮箱草稿里，面试时间却在另一条聊天里。几天后再回来，花的第一份力气往往是想清楚自己上次做到哪一步。

Job Search Harness 的想法很简单。把岗位、申请和沟通放到同一个本地工作台，再把判断理由和下一步一起留下。

拿到一份 JD，可以把它和求职偏好放在一起看。符合的地方、明确有差距的地方，以及对方没说清的条件，各有记录。准备申请时，先核对收件人和简历版本，再查看草稿或发送凭据。收到面试邀约时，从消息里看到关联岗位，把时间选择留在「待我决定」。这样下一次回来，可以从上次停下的地方接着做。

配置账号后，工作台可以检查网易 126 招聘邮箱，并发送你授权的邮件。BOSS 直聘、猎聘和鱼泡的站内动作由你在已登录的浏览器完成，工作台保存待办和经过核实的结果。匹配复核可以选用已在本机登录的 Codex CLI，演示无需任何外部账号。

用 `./scripts/bootstrap.sh --demo` 和 `./scripts/serve.sh` 就能运行一份带虚构岗位、消息和模拟发送的演示。README 首屏附近也有一段可以直接复制给 Codex、Claude Code 或 Cursor Agent 的安装提示词。

如果它让你的求职少了一点混乱，欢迎点个 Star。也欢迎分享使用体验，或一起完善下一个功能。 [GitHub 仓库和安装说明](https://github.com/milkrabbitt/job-search-harness)
