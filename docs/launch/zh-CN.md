# Job Search Harness 项目介绍

## 一句话

Job Search Harness 是一个本地求职工作台，用你的求职条件筛岗位，用你确认的资料准备申请，集中保存招聘回复和面试待办。

## 短帖

填上目标岗位、城市和薪资要求，在本机登记个人经历和已批准的简历 PDF。Job Search Harness 会检查你配置的招聘来源，列出匹配的岗位和还要问清的条件。已发送的材料、招聘方的回复和面试待办都能按岗位回看。

接通网易 126 后，可以授权它处理部分明确的邮件请求。面试时间、薪资和 Offer 由你决定。仓库有一套不需要真实简历或邮箱的离线演示。

[查看项目和安装方式](https://github.com/milkrabbitt/job-search-harness)

## 长帖

Job Search Harness 适合已经在看多个岗位、需要记住每一份申请进度的人。先填岗位方向、城市、薪资要求和排除项，在本机登记经历、公开作品链接和允许发送的简历 PDF。工作台从已配置的招聘来源查找岗位，把匹配点、不符合的条件和未知项列开。

选好岗位后，可以用已核对的收件人和简历版本生成邮件草稿。已经同步或手动登记的招聘消息可以按岗位查看；还能回看之前发的是哪版简历、有没有发送凭据。接通网易 126 后，部分明确的资料请求和有核实依据的简单问题可按授权回复。收到面试邀约会进入「待我决定」。BOSS 直聘、猎聘和鱼泡的站内动作仍在已登录的浏览器里完成。

岗位页展示招聘方给出的薪资区间，可以按自己的底线筛选。投递台账可导出 CSV 做手动对照；未公开的薪资需要向招聘方核实。

macOS 和 Linux 都能跑离线演示。克隆项目后运行 `./scripts/bootstrap.sh --demo` 和 `./scripts/serve.sh`。如果平时用 Codex、Claude Code 或 Cursor，README 提供了可复制的安装提示词。
