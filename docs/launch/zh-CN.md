以下是外部发布草稿；仓库文案已按实际功能编写。

## 一句话

公司有招聘系统。你，也该有求职系统。Job Search Harness，把岗位、申请、招聘对话和下一步留在自己的电脑上。

## 短帖

求职最消耗人的，有时是那些反复确认的小事：
这个岗位投过没有？发的是哪版简历？招聘方上次说了什么？

所以做了 Job Search Harness——一个开源、本地运行的求职工作台。

看岗位匹配依据，保存申请和发送证据，把招聘对话与待办接起来。下次打开，知道从哪里继续。

先用虚构数据跑一次演示，不需要交出简历、邮箱授权或模型账号。还准备了安装提示词，可以交给自己的编程助手来安装。

## 长帖

公司有招聘系统。你，也该有求职系统。

收藏夹里是岗位，文件夹里是简历，聊天软件里是招聘对话，表格里是上周的进度。一次申请被拆成了好几个地方，下一次打开，又要重新找回上下文。

Job Search Harness 想解决的，就是这段重复劳动。

它把岗位来源与匹配依据、申请正文与批准的简历、招聘对话与下一步放到同一个本地工作台。合并重复岗位，区分准备好的申请和已经有回执的申请，遇到发送结果不明确的邮件，先核验再决定下一步。

系统用 Python 和 SQLite 运行，提供备份与恢复，MIT 开源。当前版本有 75 项离线测试。无需模型账号即可运行虚构数据演示；可选模型复核使用本机已登录的 Codex CLI。

v0.1.0 还是预览版：基础功能支持 macOS / Linux，界面为中文，部分真实渠道依赖 macOS 钥匙串，站内申请和聊天由操作者在浏览器里完成。具体边界已写在文档里。
