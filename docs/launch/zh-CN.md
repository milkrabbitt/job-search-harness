# 先看清匹配，再决定投递。

Job Search Harness 是一个开源的本机求职工作台：用你确认的简历对照 JD，把匹配依据、薪资条件和后续跟进放在一起。

## 可直接发布的短文案

简历里哪段经历能对上这份 JD？招聘方写的 20–30K，到底按几薪？上一轮沟通之后，该做什么？

Job Search Harness 把这些问题放进了同一个求职工作台。上传 PDF、核对经历，再授权自己选择的模型复核：相关经历、缺口、待确认项，都带着原文依据。选 2–6 个岗位，直接对照薪资口径；没写清楚的地方，就留着问招聘方。接通并授权网易 126 后，还能按规则处理常规邮件和一次未回复跟进，面试与条件协商交给你决定。当前 126 凭据接入需要 macOS 钥匙串；BOSS、猎聘站内操作由你在浏览器完成。

已经开源，也准备了无需真实简历和邮箱的离线演示。如果你也想把求职记录整理清楚，欢迎点个 **Star**，下次找工作时直接回来用。

GitHub：<https://github.com/milkrabbitt/job-search-harness>

## 44 秒口播与分镜

这是待拍摄的脚本。使用独立的虚构演示资料录制实际页面，全程保留角标 **「虚构资料 · 本机演示 · 模拟邮件」**。人物、公司、简历和招聘消息均使用虚构内容；镜头之间可以剪辑，展示操作结果。

| 时间 | 实际画面与操作 | 口播 | 屏幕重点 |
| --- | --- | --- | --- |
| 0–4 秒 | 打开一份已保存的虚构岗位详情，停在任职要求处。 | 这份工作，凭什么值得投？先把依据摆出来。 | 大字幕：先看清匹配，再决定投递。 |
| 4–11 秒 | 在「我的经历与简历」选择演示 PDF，点击「上传并读取 PDF」；剪到提取结果，核对文字并确认。 | 上传简历，核对提取的经历，确认之后再用于匹配。 | 保留「核对简历文字」与确认操作。 |
| 11–21 秒 | 展示该虚构岗位的经历匹配结果，依次框选一条关联经历、一处缺口和对应引用。 | 对照岗位要求，哪些经历有关联、哪里还有缺口，都能回到原文核对。 | 放大真实页面中的引用和待核实项；模拟模型返回时另标「模拟模型结果」。 |
| 21–29 秒 | 打开「薪资对比」，选 2–3 个演示岗位，点击「查看对比」；同时展示明确的人民币月薪与 13 薪、以及待确认的报价。 | 几份工作放在一起，先看薪资口径。没写清楚的，就留着确认。 | 原始报价、明示薪数、年额与「待确认」。 |
| 29–38 秒 | 展示模拟邮件会话，再切到「待我决定」中的虚构面试邀请。 | 126 邮箱授权后，按规则处理常规跟进。面试和条件协商，交给你决定。 | 就近字幕：126 接入需 macOS 钥匙串；本镜头为模拟邮件。 |
| 38–44 秒 | 回到项目 GitHub 首页，停留在项目名、演示入口和 Star 按钮附近。 | GitHub 搜 Job Search Harness。觉得有用，点个 Star，下次找工作时回来用。 | 显示完整地址：github.com/milkrabbitt/job-search-harness。 |

匹配结果须来自演示运行中实际保存的结果，引用能对应到演示经历与 JD。全片使用本机产品页面和 GitHub 页面即可，无需招聘平台账号或真人聊天记录。

执行录制请使用：[标准化 Codex 录制提示词](../video-demo-prompt.md)。它负责准备演示、核对画面和生成视频；本页提供短视频的表达与节奏。
